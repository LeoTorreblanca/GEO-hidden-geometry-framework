# Historical preprint

This directory preserves an early GEO preprint for historical and provenance
purposes.

The document records an earlier stage of the GEO research program and should
not be interpreted as the complete or authoritative description of the current
mathematical architecture.

For the current framework definitions, use the repository root `README.md`
together with the maintained mathematical documentation.

In particular, the present canonical architecture distinguishes the structural
parameter \(\eta\) from the application-dependent effective state
\(\mu_{\mathrm{eff}}\), with general radial law

$$
R^3=\mu_{\mathrm{eff}},
$$

or equivalently

$$
R=\mu_{\mathrm{eff}}^{1/3}.
$$

Historical versions are retained to preserve the development record of GEO.
