### 1. Propósito del documento
Este documento fija el núcleo interno de GEO: las relaciones, constantes, operadores y la lectura proyectiva que componen el marco geométrico antes de cualquier comparación observacional o auditoría cosmológica externa. GEO propone que ciertos observables físicos pueden entenderse como proyecciones de una geometría efectiva subyacente.

### 2. Hipótesis mínima GEO
* **H1 - Conservación proyectiva:** La estructura observable se lee como una partición de una unidad geométrica conservada.
* **H2 - Frontera activa:** No toda la unidad participa de manera visible; existe una fracción activa y una fracción no expresada directamente.
* **H3 - Transferencia geométrica:** La diferencia entre lecturas se interpreta como un efecto de proyección, foco o transferencia.
* **H4 - Escala operativa:** La escala observable emerge mediante una ley de raíz cúbica de una magnitud efectiva $\mu$.
* **H5 - Predicción efectiva:** Si la geometría interna queda fijada, la proyección observable no requiere ajustar un parámetro externo para cada caso.

### 3. Partición fundamental
La forma base del marco se expresa como una unidad proyectiva:
$$T = A + B + L$$

| Símbolo | Lectura GEO | Rol |
| :--- | :--- | :--- |
| **T** | Campo total / unidad proyectiva | Estructura completa que contiene las componentes |
| **A** | Componente activa | Sector expresado, observable o material |
| **B** | Fondo / base / frontera | Sector de restricción o reserva geométrica |
| **L** | Componente libre | Gravedad / lambda / grado libre de proyección |

| Relación | Valor | Lectura interna |

### 5. Lectura física de los operadores

* **$\eta$:** No significa un ajuste numérico aislado; significa la propiedad de partición activa del objeto geométrico.
* **$f_c$:** No significa un coeficiente libre; significa la frontera causal de transferencia (raíz de la partición).
* **$B$:** No significa materia oscura literal; significa la reserva/fondo geómico no expresado directamente.
* **$\theta$:** No significa un ángulo elegido por conveniencia; significa la orientación efectiva de lectura/proyección del anillo.
* **$\Phi$:** No significa un número observado a posteriori; significa la profundidad/amplitud coherente del anillo GEO.
* **$\alpha$:** No significa un parámetro externo; significa la proyección observable de $\Phi$ sobre $B$ bajo la orientación de enlace.

---

### 6. Cadena proyectiva interna y definición de $\Phi$
El puente interno condensado se ejecuta bajo la siguiente secuencia operativa:

$$\eta \rightarrow f_c \rightarrow B \rightarrow \Phi \rightarrow \alpha \rightarrow R \rightarrow \text{Observable}$$

Para blindar el puente formal, $\Phi$ se define explícitamente como el **operador de amplitud efectiva de transferencia coherente del anillo GEO**. No mide un observable externo, sino la capacidad interna del anillo para convertir la partición y la frontera en una proyección efectiva mediante la fórmula:

$$\text{Observable}_{\text{GEO}} = \text{Base} \cdot (1 + \alpha \cdot \text{Operador}_{\text{GEO}})$$
